# Limnoria container v0.1.0

Initial Ploos AS container release for Limnoria.

## Included

- Limnoria pinned to `ac135083987a3a3121a9ba54f980902b29da10c7`
- Python 3.13 slim-bookworm runtime
- non-root UID/GID 1000
- persistent `/data` working directory
- first-run wizard workflow
- explicit config selection with `LIMNORIA_CONFIG`
- `tini` PID 1
- runtime healthcheck
- Docker Compose example
- rootless Podman Quadlet example
- `linux/amd64` and `linux/arm64` publication workflow
- GHCR tags for edge, semver and latest releases
- SBOM and provenance attestations from the BuildKit publishing workflow
- MIT packaging license with upstream BSD-3-Clause notice

## Image

`ghcr.io/ploos-as/limnoria:0.1.0`

The release tag should be created only after the `edge` build and runtime smoke checks pass.
